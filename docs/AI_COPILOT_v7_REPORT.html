1. نظرة عامة

EPI Copilot هو نظام ذكاء اصطناعي مدمج داخل منصة مشرف التحصين الصحي الموسع (EPI Supervisor). يعمل كـ Copilot ذكي يفهم بيانات النظام ويحللها ويقدم تقارير وتوصيات بناءً على بيانات حية من قاعدة البيانات.

تدفق المعالجة

1 طلب المستخدم → فحص الأمان (Injection Guard)
2 كشف التحيات → رد فوري (بدون LLM)
3 تصنيف النية (Intent) → تحديد المعرفة المطلوبة
4 فحص الكاش → رد مخزن (إن وجد)
5 جلب البيانات الحية + ذاكرة المحادثة
6 بناء System Prompt (ديناميكي حسب النية)
7 Multi-step Tool Calling (حتى 5 جولات)
8 تأكيد الكتابة (إن لزم) → تنفيذ → تسجيل
9 إرجاع الرد + تحديث الكاش + ذاكرة المحادثة

التأكيد (Confirmation Flow)

1 المستخدم: "اعتمد كل إرساليات تعز"
2 AI يستدعي update_submission_status → يرجع needs_confirmation
3 AI يقول: "🔒 هل تريد تأكيد تحديث 47 إرسالية؟"
4 المستخدم: "نعم"
5 AI يستدعي نفس الأداة مع _confirmed=true → ينفذ
6 📝 Audit Log يسجل العملية

6. واجهة البرمجة (API)

الطلب (Request)

POST /functions/v1/ai-chat-v3
Headers:
  Authorization: Bearer <user-jwt>
  Content-Type: application/json

Body:
{
  "message": "نص السؤال",           // مطلوب (أو template)
  "history": [...],                  // اختياري — تاريخ المحادثة
  "mode": "chat",                    // اختياري — chat|suggestions|health|usage|feedback|model_status
  "template": "daily",               // اختياري — قالب تقرير
  "stream": false,                   // اختياري — SSE streaming
  "feedback": {                      // اختياري — mode=feedback
    "rating": "up",
    "comment": "ملاحظة",
    "intent": "query_submissions"
  },
  "message_id": "uuid"               // مطلوب مع feedback
}

الرد (Response)

{
  "reply": "نص الرد من AI",
  "source": "groq_multi_step",       // groq|huggingface|openrouter|zai|mimo|response_cache|greeting_handler
  "model": "llama-3.3-70b-versatile",
  "intent": "query_submissions",
  "confidence": 0.85,
  "intents": ["query_submissions", "analyze_trend"],  // اختياري — أسئلة مركبة
  "messageId": "uuid",
  "toolsUsed": ["get_submissions", "get_governorate_performance"]
}
