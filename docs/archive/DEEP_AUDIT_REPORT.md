### ❌ الغلط 1: BCG — لا يوجد حد أقصى للعمر
**الموقع:** `vaccination_service.dart` → Vaccine id: `bcg`

**الحالي:**
```dart
notes: 'يُعطى عند الولادة أو في أقرب فرصة ممكنة'
```
(لا يوجد أي ذكر للحد الأقصى)

**الصحيح:**
```
الحد الأقصى للعمر: سنة واحدة (12 شهر)
بعد السنة لا يُعطي أبداً
```

**التأثير:** النظام لن يمنع إعطاء BCG لطفل عمره 3 سنوات مثلاً.

---

### ❌ الغلط 2: IPV — جرعة واحدة فقط (يجب أن تكون جرعتين)
**الموقع:** `vaccination_service.dart` → Vaccine id: `ipv`

**الحالي:**
```dart
description: 'يُعطى جرعة واحدة مع الجرعة الثالثة من OPV',
doseNumber: 'جرعة واحدة',
notes: 'يُعطى مع OPV3 لتعزيز المناعة',
```

**الصحيح:**
```
IPV: جرعتان
- الأولى عند 14 أسبوع (مع OPV3 + Penta3 + PCV3)
- الثانية عند 9 أشهر (مع MR1 + OPV4)
```

**التأثير:** النظام لا يعرف بوجود IPV2 عند 9 أشهر. لن يطلب أو يتابع الجرعة الثانية.

---

### ❌ الغلط 3: فيتامين أ — عمر خاطئ + جرعة خاطئة
**الموقع:** `vaccination_service.dart` → Vaccine id: `vitA_2`

**الحالي:**
```dart
id: 'vitA_2',
nameAr: 'فيتامين أ - جرعة 12 شهر',
dueMonths: 12,
doseNumber: 'جرعة واحدة (كبسولة حمراء)',
notes: 'تُعطى في عمر 12 شهر. كبسولة حمراء تحتوي على 200,000 وحدة دولية',
```

**الصحيح:**
```
الجرعة الأولى من فيتامين أ: عند 9 أشهر (وليس 12 شهر)
الجرعة: 100,000 وحدة دولية (وليس 200,000)
اللون: كبسولة زرقاء (وليس حمراء)
```

**التأثير:** النظام يعطي الجرعة الأولى من فيتامين أ متأخرة بـ3 أشهر وبجرعة مضاعفة.

---

### ❌ الغلط 4: فيتامين أ — الجرعة الثانية عند 18 شهر غير موجودة ككيان مستقل
**الموقع:** `vaccination_service.dart`

**الحالي:** يوجد `vitA_3` عند 18 شهر (200,000 وحدة) — هذا صحيح.

**لكن:** لا يوجد كيان منفصل لفيتامين أ عند 9 أشهر بجرعة 100,000 وحدة.

**المطلوب إضافته:**
```dart
Vaccine(
  id: 'vitA_1',
  nameAr: 'فيتامين أ - جرعة 9 أشهر',
  nameEn: 'Vitamin A - 100,000 IU (9 months)',
  dueMonths: 9,
  doseNumber: 'جرعة واحدة (كبسولة زرقاء)',
  route: 'oral',
  notes: 'تُعطى في عمر 9 أشهر مع MR1. كبسولة زرقاء تحتوي على 100,000 وحدة دولية',
)
```

### ❌ الغلط 5: DTP Booster عند 18 شهر — يجب أن يكون Penta (خماسي)
**الموقع:** `vaccination_service.dart` → Vaccine id: `dtp_booster`

**الحالي:**
```dart
id: 'dtp_booster',
nameAr: 'الخناق والكزاز والسعال الديبي (DTP) - جرعة معززة',
```

**الصحيح:**
```
يجب أن يكون Penta4 (الخماسي التعزيزية) وليس DTP
Penta4 يحتوي على: الدفتيريا + الكزاز + السعال الديكي + الكبد B + المستديمة
```

**التأثير:** النظام يعتبر الجرعة التعزيزية عند 18 شهر هي DTP (3 مكونات) بدلاً من Penta (5 مكونات).

---

### ❌ الغلط 6: DTP عند دخول المدرسة — يجب أن يكون Td
**الموقع:** `vaccination_service.dart` → Vaccine id: `dtp_school`

**الحالي:**
```dart
id: 'dtp_school',
nameAr: 'الخناق والكزاز والسعال الديبي (DTP) - جرعة المدرسة',
```

**الصحيح:**
```
Td (وليس DTP) — الكزاز والخناق فقط (بدون السعال الديكي)
```

**التأثير:** النظام يعطي DTP بدلاً من Td عند دخول المدارس.

### ❌ الغلط 7: Td للبنات عند 12 سنة — غير موجود في الدليل
**الموقع:** `vaccination_service.dart` → Vaccine id: `td_girls`

**الحالي:**
```dart
id: 'td_girls',
nameAr: 'الكزاز والخناق (Td) - للبنات',
dueMonths: 144, // 12 years
```

**الصحيح:**
```
هذا اللقاح غير موجود في جدول التحصين الروتيني للدليل المحدث
الجدول يتضمن فقط Td عند دخول المدارس (5-7 سنوات) للجميع
```

**ملاحظة:** قد يكون موجوداً في برامج أخرى (مثل تحصين الحوامل) لكنه ليس في الجدول الروتيني للأطفال.

### ❌ الغلط 9: لا يوجد حدود عمرية قصوى لأي لقاح
**الموقع:** `vaccination_service.dart` — جميع اللقاحات

**الحالي:** لا يوجد أي حقل `maxAge` أو `maxWeeks` أو `maxMonths` في أي لقاح.

**المطلوب إضافة حقل `maxAge` لكل لقاح:**

| اللقاح | الحد الأقصى |
|--------|-----------|
| BCG | < سنة (12 شهر) |
| HepB | < 5 سنوات |
| OPV | < 5 سنوات |
| IPV | < 5 سنوات |
| Penta | < 5 سنوات |
| PCV | < 5 سنوات |
| Rota | < سنتين |
| MR | < 5 سنوات |
| Vitamin A | < 5 سنوات |
| Td (مدرسي) | < 7 سنوات |

### ❌ الغلط 10: Chunk 247 — جدول فوق العام — أخطاء متعددة
**الموقع:** `local-knowledge.ts` → index 247 → section: `جدول_الجرعة_الصفرية_فوق_العام`

**أ. Rota الحد الأقصى خاطئ:**
```
الحالي: "لا يُعطي الروتا بعد عمر 32 أسبوع"
الصحيح: لا يُعطي الروتا بعد عمر سنتين (وليس 32 أسبوع)
```

**ب. فيتامين أ خاطئ:**
```
الحالي: "فيتامين أ — 2000 وحدة دولية"
الصحيح: 100,000 وحدة دولية (وليس 2000)
```

**ج. لا يوجد ذكر لـ BCG:**
```
الحالي: لا يوجد BCG في الجدول
الصحيح: يجب ذكر BCG (يُعطي إذا كان الطفل أقل من سنة)
```

**د. Penta3 التوقيت خاطئ:**
```
الحالي: "الزيارة الرابعة — بعد 3 أشهر من الزيارة الثانية: Penta3"
الصحيح: بعد 6 أشهر من الزيارة الثانية (وليس 3 أشهر)
```

**هـ. ملاحظة خاطئة عن اللقاحات:**
```
الحالي: "جميع اللقاحات الأخرى لا يوجد لها أقصى عمر"
الصحيح: جميع اللقاحات الأخرى الحد الأقصى 5 سنوات
```

### ❌ الغلط 11: Chunk 248 — جدول فوق العامين — أخطاء متعددة
**الموقع:** `local-knowledge.ts` → index 248 → section: `جدول_الجرعة_الصفرية_فوق_العامين`

**أ. Rota خاطئ:**
```
الحالي: "لا يُعطي الروتا في هذا الجدول (تجاوز العمر الأقصى 32 أسبوع)"
الصحيح: تجاوز العمر الأقصى سنتين (وليس 32 أسبوع)
```

**ب. PCV خاطئ:**
```
الحالي: "لا يُعطي PCV في الزيارة الثانية (يُعطى فقط في الزيارة الأولى)"
الصحيح: PCV يُعطي في الزيارة الأولى فقط — هذا صحيح ✅
لكن التوقيت في الزيارة الأولى يجب أن يكون: 3 جرعات + تشجيعية
(وليس جرعة واحدة كما يوحي النص)
```

**ج. فيتامين أ خاطئ:**
```
الحالي: "فيتامين أ يُعطى 2000 وحدة"
الصحيح: 100,000 وحدة دولية (وليس 2000)
```

**د. لا يوجد ذكر لـ BCG:**
```
الحالي: لا يوجد BCG
الصحيح: BCG يُعطي إذا كان الطفل أقل من سنة
```

### ❌ الغلط 12: Chunk 249 — أمثلة الجرعة الصفرية — أخطاء متعددة
**الموقع:** `local-knowledge.ts` → index 249 → section: `أمثلة_الجرعة_الصفرية`

**أ. BCG يُعطي في أمثلة عمر 9 أشهر و18 شهر:**
```
الحالي (مثال 2): "BCG + OPV1 + Penta1 + PCV1 + Rota1 + IPV1 + MR1"
الحالي (مثال 3): "OPV1 + IPV1 + Penta1 + PCV1 + Rota1 + MR1" (لا يوجد BCG — صحيح)

المشكلة: في المثال 2 (عمر 9 أشهر) لا يزال يُعطي BCG
الصحيح: BCG يُعطي فقط إذا كان الطفل أقل من سنة واحدة
إذا عمره 9 أشهر → يُعطي BCG ✅ (لا يزال تحت السنة)
إذا عمره 18 شهر → لا يُعطي BCG ❌ (تجاوز السنة)
```

**ب. فيتامين أ:**
```
الحالي: "فيتامين أ 1000 وحدة"
الصحيح: 100,000 وحدة دولية (الأرقام مكتوبة بشكل مختصر قد يُفهم خطأ)
```

**ج. القاعدة الأساسية خاطئة:**
```
الحالي: "لا يوجد أقصى عمر لأي لقاح ما عدا الروتا (32 أسبوع)"
الصحيح:
- BCG: أقصى عمر سنة واحدة
- Rota: أقصى عمر سنتين
- الخماسي + باقي اللقاحات: أقصى عمر 5 سنوات
- Td (مدرسي): أقصى عمر 7 سنوات
```

| الخطأ | الخطورة | التأثير |
